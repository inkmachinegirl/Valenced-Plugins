**Plugins**
• **AO3 Reader** `1.0.0`: read AO3 links in a clean reader with themes, text size and a library
• **Auto Collapse** `1.2.0`: collapse categories with nothing new when you open a server
• **Better DMs** `1.3.0`: colours, labels, emoji and pins for DMs, tabs (with a Groups tab), unread and mutual-server hints, a name banner, a send check for careful chats and private nicknames
• **Block by ID** `1.3.2`: block anyone by pasting their user ID, even with no shared server or DM
• **Bulk Mute** `1.0.0`: select channels and mute or unmute them all at once
• **Compact Status** `1.0.1`: a smaller status sheet, the statuses as one row of icons
• **Default Typing Indicator** `1.0.0`: everyone's typing indicator as Discord's plain dots, no wiggling custom emoji
• **DM Cleanup** `1.0.2`: a smaller Add Friends button, tick DMs and close them all at once
• **DM Details+** `1.3.1`: hide the New Group button and Files tab in DM details, and add Stickers and Emoji tabs
• **Download Emojis & Stickers** `1.1.1`: long-press a server to save all its emojis or stickers as a zip
• **Emoji Sorter** `1.1.0`: sort the emoji picker's servers A to Z, by most emojis or most animated, and hide the ones you can't use
• **Embed Playback** `1.4.1`: play YouTube embeds and links over the chat or in a floating window that keeps playing while you scroll
• **Floating Browser** `1.7.1`: a browser that floats over Discord, with bookmarks and extensions
• **Folder Mute** `1.0.0`: hold a folder to mute or unmute every server in it, for a set time or until you turn it back on
• **Forum Grid** `1.1.3`: forum posts as a grid with images, filters and more sorting
• **Friends Export** `1.0.0`: export your friends list as text, CSV or JSON with `/friendslist`, copy it or save it to a file
• **Hide Blocked Typing** `1.0.0`: never see blocked or ignored people typing
• **Hide DMs** `1.0.4`: hide chosen DMs and group DMs, or all of them, without leaving them
• **Hide Empty Days** `1.1.0`: remove date lines for days with nothing to show
• **Hide Server Banners** `1.1.2`: compact header in every server, no banners
• **Hide Server Guide** `1.0.0`: remove the Server Guide row from every server
• **Hide Get Started** `1.0.0`: hide the Get Started progress bar from every server
• **Hide Stream Previews** `1.0.1`: hide the floating call preview after leaving the call screen
• **Launch Pad Reduced Motion** `1.0.0`: Launch Pad opens and closes without animations, the rest of Discord keeps them
• **Ignore Apps** `1.0.4`: hide messages from bots Discord won't let you block, like MEE6
• **Ignore by Role** `1.1.0`: type a server and a role, then pick who with that role to ignore
• **Meow Picker** `1.5.0`: a cat button with a picker full of meows and cat kaomoji
• **Never Talked** `1.0.1`: mark people in the member list who never talked in that server
• **No Blackout** `1.0.2`: stop the screen going black in calls when the proximity sensor is covered
• **Plugin Sort** `1.0.0`: sort plugins by resource use, stutters, calls, startup or hooks, and filter the heavy or unused ones
• **Profile Widgets** `1.2.1`: edit your game widgets right on your profile, with comments and tags
• **Quick Access** `1.4.4`: reload, Friends, Plugins and Performance Monitor buttons on the YouBar, each with its own switch
• **Quick Folders** `1.2.0`: long-press a server to move it to a folder, no dragging
• **Shop Browser** `1.13.0`: the Shop like on desktop, with Browse, sorting and filters
• **Smaller Media** `1.2.2`: make images, GIFs and videos in chat 30-50% smaller, still full size when tapped
• **Spectators** `1.0.2`: see who's watching a stream, with join/leave notices and a notification with the count while you stream
• **Stream Tools** `1.0.2`: auto-watch streams, a volume and switch bar, and a clean view
• **Unfollow Category** `1.0.0`: untick every channel in a category at once in Channels & Roles
• **Watch Together Ad Block** `1.0.0`: no YouTube ads in Discord's Watch Together
